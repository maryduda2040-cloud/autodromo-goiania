AUTODROMO DE GOIANIA — WEBAR

1. Envie index.html, pista.mp4 e .nojekyll para a raiz do seu repositorio GitHub.
2. Ative GitHub Pages em Settings > Pages.
3. Publique a partir da branch main e da pasta / (root).
4. Abra o endereco HTTPS gerado no Chrome para Android em aparelho compativel com WebXR/ARCore.
5. No jogo: INICIAR CORRIDA -> aponte para o chao -> COLOCAR PISTA AQUI.

O projeto usa WebXR immersive-ar + hit-test e Three.js via CDN.
O fundo cinza aproximado do video (#343434) e removido por shader.

O GitHub Pages hospeda os arquivos sem dominio proprio ou hospedagem paga.
